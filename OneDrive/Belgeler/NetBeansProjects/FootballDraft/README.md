# ⚽ Football Draft

Football Draft is a Java-based football squad building game where players create their own starting XI by selecting a formation and choosing footballers based on their overall ratings.

## 🎮 Features

- 👤 Enter player name
- ⚽ Select favorite football team
- 📋 Choose a starting XI formation
- 🧤 Select a goalkeeper from 5 options
- 🛡️ Select defenders from available options
- ⚙️ Select midfielders
- ⚡ Select attackers
- ⭐ Every football player has an overall rating
- 📊 Calculate the overall rating of the created squad
- 🏆 Compare the squad with other players through a leaderboard

## 🛠️ Technologies

- Java
- Object-Oriented Programming (OOP)
- Java Collections
- NetBeans
